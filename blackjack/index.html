Hi-Loカードカウントで、残っているカードの偏りまで判断する 基本戦略・応用戦略を覚えた後に使う上級者向けです。まず通常の最適アクションを判断し、必要な場面だけTrue Countで補正します。
カードカウントは「次のカードを当てる」方法ではありません。公開されたカードを数え、残りのシューに高いカード／低いカードがどちらに多く残っているかを推定する方法です。
判断する順番 ① Hi-Loを数える → ② True Countへ変換 → ③ 基本/応用戦略を確認 → ④ Index該当時だけDeviation

1. Hi-Loの数え方

2・3・4・5・6+1Low Card
7・8・90Neutral
10・J・Q・K・A-1High Card
例 3 → 5 → K → 7 → A → 4 +1 +1 -1 +0 -1 +1 ＝ Running Count +1

2. Running Count → True Count

True Count Running Count ÷ 残りデック数
例 Running Count +8 / 残り4デック True Count = +2
＋方向10・絵札・Aが相対的に多く残っている
0付近大きな偏りがない
－方向2〜6が相対的に多く残っている

5. BETへの使い方

TCが高いプレイヤーに有利な高カードが残りやすい状態
TCが低いプレイヤー側の優位性は下がる方向
重要「負けたから増やす」のではなく、シューの構成を根拠に判断する
BET額の具体的な増減幅は、資金量・テーブルMIN/MAX・許容リスクで変わるため、このゲームでは固定のBETスプレッドを上級戦略として指定していません。
優先して覚えるなら：まず Insurance +3、16 vs 10、15 vs 10。その後に上から順番にDeviationを増やしていくと覚えやすいです。
Hitテーブルを指で軽く叩く
Stand手のひらを下に向けて、左右に振る
Double元のBETと同額のチップを追加し、指を1本立てる
Split元のBETと同額のチップを追加し、指を2本立てる
Surrender「Surrender」と伝える。テーブルでは人差し指でBETの後ろに横線を引くように示す場合もある
Surrenderは最初の2枚が配られた直後のみ選択できます。
4・5・6はディーラーがバーストしやすい無理にHitせず、Standを選ぶ場面が増えます。
AA・88はSplitこの2組はSplitを優先。
10・10はSplitしない20は非常に強いので、そのままStand。
5・5はSplitしない合計10としてDoubleを狙う。
Insuranceは基本的に選ばない長期的には不利になりやすいサイドベットです。
迷ったら基本戦略を優先直前の勝敗や感覚でアクションを変えない。
